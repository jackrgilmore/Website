#+title: jackgilmorecreative.com

A plain HTML/CSS/JavaScript site, served by GitHub Pages. No build tools: the
only "build" is Emacs exporting the writing. Everything I edit is Org.

How all of it works, file by file and line by line, is taught by the Emacs on
the Web tutorial in my dotfiles (=SPC n w t=, or =~/dotfiles/tutorial/eow-lessons/=).

* Updating the site (from Emacs)

All under =SPC n w= (set up in =~/dotfiles/doom/.config/doom/config.org=):

| Key         | Does                                                   |
|-------------+--------------------------------------------------------|
| =SPC n w n= | New piece of writing                                   |
| =SPC n w e= | New video or comic: asks which series/season or group  |
| =SPC n w a= | Open =content/animation.org= (reel, Hat Guy, gallery)   |
| =SPC n w c= | Open =content/comics.org=                               |
| =SPC n w g= | Make the org-roam note I'm in public (or private)      |
| =SPC n w p= | Publish: export writing + garden to HTML               |
| =SPC n w v= | Preview at http://localhost:8000                       |
| =SPC n w P= | Publish, commit and push: live in a minute or two      |
| =SPC n w x= | Share a blog post: email, Instagram and Facebook       |
| =SPC n w b= | Set a book's cover (in the book)                       |
| =SPC n w t= | The tutorial: how this site works                      |

Without Emacs: edit the Org files anywhere (even on github.com) and push. Only
writing and garden notes need the publish step:
=emacs --batch -l publish.el -f jg-site-publish=.

* Designing the pictures

You can redo these in Photoshop, Inkscape or anything else; the next publish
uses them (and redraws every post's pictures):

- *The card*, =og.png= (1200×630): what a shared link shows when the page has
  no picture of its own. =og.svg= is its source, for Inkscape: Hat Guy on it
  is =favicon.svg= itself, so it follows the icon, and =og.png= is made from
  it when you publish, along with =design/card-dark.png=, the same card in
  the site's dark colors (the Instagram pictures are dark, and it's their
  last slide). To make
  =og.png= in Photoshop instead, delete =og.svg=. =og.jpg= is made from
  =og.png= when you publish.
- *The icon*, =favicon.svg= (64×64): draw it in Inkscape. Publishing remakes
  =favicon.ico=, =apple-touch-icon.png=, the cards and =design/hat-guy.png=
  (Hat Guy on the story of a post with no picture) from it
  (=tools/icons.sh=, which needs =brew install librsvg imagemagick=; run it
  by hand to see them without publishing).
- *The story's background*, =design/story.png= (1080×1920). The post's
  picture, title and description go on top, in the boxes
  =design/story.json= gives (x and y from the top left, in pixels; text size,
  font, color, alignment; the picture's corner rounding). Lay
  =design/story-guide.png= over your design as a top layer to see where they
  land and which strips Instagram's buttons cover; it's redrawn when you
  change =story.json=. Fonts are PostScript names, as Font Book shows them
  (=Georgia-Bold=). Delete =story.png= for a plain background. To start
  over from the plain dark one: build the tool (=swiftc tools/slides.swift
  -o /tmp/slides=) and run =/tmp/slides --starter design design/card-dark.png=.

* Things to know

- Each blog post also gets Instagram pictures in =social/POST/=, drawn by
  =tools/slides.swift= when you publish, in the site's dark colors: square
  slides of its text in Georgia (9 at most) and a slide about the site, posted as a carousel; and
  =story.jpg=, phone-sized, for the story. They're only redrawn when the
  post or a design file changes.
- =examples/= holds example books and scripts, laid out like =content/=. They're
  never published; =SPC n w V= builds a throwaway copy of the site with them
  added and previews it at localhost:8001.

- Every piece (writing, garden notes, books and chapters, comics, series,
  episodes, videos) has a Share button (just an icon): the share sheet on a
  phone; on a computer it copies the link, turns into a check mark and pops up
  "Link copied". It's one handler in =nav.js= for any =[data-share]=
  button; pages made in the browser call =shareButton(url, title)=.

- A piece's date is the day it goes online. Each publish dates today anything
  whose page isn't in the last commit yet (a draft made public, a note just
  tagged =publish=, a new video or comic), writing it into the Org file. To
  backdate something, push it first, then change its date.
- New blog posts are shared when they're pushed from Emacs: emailed to the
  subscribers (Buttondown, who keeps the list), posted to
  Instagram (@jackgilmorecreative) through its API, and Facebook's share
  window opens with the caption on the clipboard (Facebook doesn't let apps
  post to personal profiles). Setup and details: "Cross-posting the blog" in
  =config.org=.

- The whole repo is public on GitHub, including drafts in =content/writing/=
  (=#+draft: t= only keeps them off the site). Keep secret drafts in =~/org=.
- =SPC n w P= commits /everything/ in this folder. =.gitignore= lists files to
  keep out (like =planning.org=).
- Instagram and TikTok videos don't have automatic thumbnails: give episodes
  from there a =:THUMB:=, or put the YouTube link in =:VIDEO:=.
- Visitors are counted by GoatCounter (=analytics.js=; no cookies, so no
  banner). Emacs shows the numbers: hyper-s or =SPC n w s=. Previews on
  localhost aren't counted; to leave out your own visits to the live site,
  open =https://jackgilmorecreative.com/#toggle-goatcounter= once per browser.
- A shared link shows the page's title, its =#+description:= (or, without
  one, its opening lines) and its first image (or =og.png=). Hand-written
  pages have theirs in their =<head>=. Facebook's Sharing Debugger and
  opengraph.xyz show what a link will look like.
- To check a page locally, use the preview (=SPC n w v=), not double-clicking
  the file: the pages load their data with =fetch=, which needs a server.
