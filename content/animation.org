# and pushing is all an update takes. (In Emacs: SPC n w a opens it, SPC n w P
# publishes and pushes.)
#
# - #+reel: above is the reel on the home page and at /reel.html.
# - A heading with :KIND: series is a show (the "streaming" view). Each heading
#   under it is an episode, or a season if it has episodes under it.
# - Any other top-level heading is a group, like "Projects" or "Independent
#   animation": it gets its own button on the animation page, and its own row
#   in the All view. Each video under it is a card. A heading under a group
#   with videos under it (and no video of its own) is a subsection, shown as
#   its own block in that group's view:
#     * Independent animation
#     ** Shorts
#     *** My short film    (a video)
# - The All view shows every series and every group as a row.
# - Properties a video can have:
#     :VIDEO:      the link that plays on the site (YouTube, Vimeo, Instagram,
#                  TikTok, or a .mp4 in the repo)
#     :YOUTUBE: :INSTAGRAM: :TIKTOK:   "watch on" buttons (any of these also
#                  plays if there's no :VIDEO:)
#     :DATE:       2026-10-25
#     :THUMB:      a custom thumbnail, relative to this file (../thumbs/x.jpg)
#     :ASPECT:     vertical or wide, if the guess is wrong
#   The text under a heading is its description.
# - Start a heading with COMMENT to hide it without deleting it.
